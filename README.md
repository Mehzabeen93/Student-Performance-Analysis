# Student Performance Analysis Dashboard

## Project Overview
This project presents an interactive Student Performance Analysis Dashboard developed using Microsoft Power BI. It analyses student academic performance, grades, attendance, study time, and gender distribution to identify meaningful insights.

## Project Objectives
- Analyse overall student academic performance.
- Compare final grades across subjects.
- Examine grade progression across three grading periods (G1, G2, G3).
- Analyse the relationship between student absences and final grades.
- Understand the impact of study time on academic performance.
- Compare student performance across schools and genders.

## Key Performance Indicators (KPIs)
- Total Student Records
- Average Final Grade
- Pass Rate
- Average Absences

## Dashboard Features
- Interactive slicers for Gender, Subject, School, and Study Time.
- Final Grade by Subject.
- Grade Progression by Subject.
- Final Grade by Study Time.
- Pass vs. Fail Analysis.
- Absences vs. Final Grade.
- Final Grade by School.
- Student Distribution by Gender.
- Grade Progression (G1–G3).

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## Key Insights
- Overall average final grade: 11.34.
- Student pass rate: 77.97%.
- Average student absences: 4.43.
- Portuguese students achieved a higher average final grade than Mathematics students.
- Female students represent 56.61% of the student records.
